CROSSBOW / DEFIB / REVIVE GUN
While using the teleport, pair it with the crossbow, defib, or revive gun for extremely consistent, near-100% hit/revive accuracy.

RANDOM ENEMY TP + AUTO SHOOT
Randomly TP to an enemy while triggering auto-shoot on the same key — the crossbow combo goes crazy.

VOTE KICK
If people start a vote kick, disconnecting via console from the match can prevent you from getting kicked through the vote.
